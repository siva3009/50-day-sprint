==================================================
PRODUCT PURPOSE
==================================================

The 50-Day Sprint is used by 2–5 college friends preparing for top-tier product and service company interviews.

The four main preparation pillars are:

DSA
LeetCode
Full Stack
Projects

The Projects section tracks practical development.

The goal is to ensure that by Day 50 the team has actually:

- Built real web applications
- Worked with frontend and backend technologies
- Designed databases
- Built APIs
- Implemented authentication
- Used Git/GitHub
- Deployed applications
- Collaborated as a team
- Can clearly explain their projects in interviews

This page should therefore feel like:

"BUILD → TRACK → COMPLETE → DEPLOY"
